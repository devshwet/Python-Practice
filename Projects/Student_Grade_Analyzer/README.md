## Features

- Accepts marks for 5 subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays pass/fail status

## Technologies Used

- Python

## How to Run

Run `grade_analyzer.py` and enter marks for 5 subjects when prompted.
