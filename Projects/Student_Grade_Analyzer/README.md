# Student Grade Analyzer

A Python program that calculates total marks, percentage, grade, and pass/fail status based on student marks.

## Features

- Accepts student name
- Accepts subject names
- Accepts marks for 5 subjects
- Validates marks between 0 and 100
- Handles invalid text input
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays pass/fail status

## Technologies Used

- Python

## How to Run

Run `grade_analyzer.py` and enter the student name, subject names, and marks when prompted.
